# Operations

Use separate Firebase projects for development and production. Review Firebase Auth, Firestore, Storage, and Vercel usage/billing monthly; set budget alerts. Review dependency updates and security advisories monthly, test rule changes in emulators, and deploy rules before app code that depends on them. Keep a rollback deployment available in Vercel and a recent tested backup.

No monitoring, alert routing, or automatic backups are configured yet. Keep private message bodies and media URLs out of logs and issue reports. For incidents, revoke affected access first, preserve relevant audit evidence, rotate credentials, restore if necessary, and tell both members what data was affected.
